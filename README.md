# adf-databricks-datamigration

Repository to hold code and artifacts for migrating Azure Data Factory (ADF) pipelines and assets to Databricks-based data migration solutions.

## Goals

- Capture ADF pipeline definitions and transform them for Databricks executions.
- Provide tooling and templates to help automate migration steps.
- Document best practices and migration checklist.

## Repository structure

This repository will include folders for:

- infrastructure/ - IaC (ARM/Bicep/Terraform) templates
- pipelines/ - exported ADF pipelines and transformation scripts
- databricks/ - notebooks, jobs, and related assets
- docs/ - design notes and migration runbooks

## Getting started

1. Clone the repository:

   git clone https://github.com/manojkumarnayak8971-ship-it/adf-databricks-datamigration.git
   cd adf-databricks-datamigration

2. Add content to the appropriate folders (infrastructure, pipelines, databricks, docs).

3. Open a PR for changes so they can be reviewed and merged into `main`.
